# Galaxy Poker

Тестовая версия приложения для управления сезоном Galaxy Poker.

## Запуск локально

Требуется Node.js 22 или новее.

```sh
npm ci
npm run dev
```

## Страницы

- `/` — расписание, сезонный рейтинг и результаты на одной странице.
- `/#/admin` — список турниров и создание турнира.
- `/#/admin/tournaments/tournament-1` — состав и роли участников, уровни блайндов, таймер, журнал раздач и автоматический расчёт стеков.
- `/#/screen/tournament-1` — табло для телевизора с игроками за столом, их ролями и ставками, блайндами и таймером.

Маршруты работают через Vue Router в hash-режиме, поэтому прямое открытие вложенных страниц совместимо с GitHub Pages.

## Демо-данные и хранение

Первый запуск создаёт локальный пример сезона по положению турнира. Без конфигурации Google Таблиц изменения сохраняются в `localStorage` этого браузера.

Для общего хранения подготовлен адаптер Google Apps Script и инструкция в `google-apps-script/README.md`. Публичное табло читает общие данные из Google Таблицы, админ-панель пишет их с отдельным ключом, а устройства обновляют состояние примерно раз в 30 секунд. Для локального запуска задайте `VITE_GOOGLE_APPS_SCRIPT_URL` в `.env.local`; для GitHub Pages добавьте одноимённую переменную в **Settings → Secrets and variables → Actions → Variables**.

Таблица очков в `src/domain/rating.ts` повторяет положение как черновой вариант. Её формулу и правила равенства результатов согласуем позже.

Чтобы вернуть исходные демонстрационные данные, открой `/admin` и нажми «Сбросить демо».

## Проведение турнира

Новый турнир получает структуру сезона и текущую дату Красноярска. До старта можно менять длительность и блайнды, добавлять уровни и перерывы. Некорректные настройки блокируют старт. Удалить участника, задействованного в начатой или завершённой игре, нельзя.

Блайнды **всегда переключаются вручную**. На нуле таймер показывает уведомление; уровень остаётся прежним. Кнопка «Следующий уровень» запускает полную длительность следующего этапа и сохраняет состояние таймера: работающий продолжает отсчёт, приостановленный остаётся на паузе. Последний уровень нельзя переключить дальше. Паузы сохраняют миллисекунды; перезагрузка не сбрасывает остаток. Новые раздачи на перерыве заблокированы; начатая раздача сохраняет свои блайнды при смене уровня.

Вносите добавленные фишки по действиям. Колл, вернувшийся к игроку после рейза, записывается в следующем столбце; хронология изменений показана в журнале раздачи. Для нескольких банков выбирайте победителей каждого отдельно. Неуравнённая часть ставки возвращается автоматически, а нечётная фишка при разделе идёт первому победителю слева от дилера. При нескольких оставшихся игроках начисление доступно только на ривере; при олл-ине улицы без дальнейших ставок можно пройти сразу.

Последние 20 расчётных операций можно отменять в обратном порядке: начисление банка, докупку, вылет и завершение турнира. Для отмены предыдущей операции сначала отмените текущую незавершённую раздачу. Отмена уже начисленного банка восстанавливает стеки и открывает раздачу для исправления. Операции отмены и журнал сохраняются вместе с игрой.

Для Google Sheets требуется **Apps Script API 6**: обновите `google-apps-script/Code.gs` и разверните новую версию по инструкции в этом каталоге. Старая версия не сохраняет сведения о побочных банках и отмене; приложение блокирует запись до обновления.

## Публикация на GitHub Pages

В репозитории уже добавлен GitHub Actions workflow `.github/workflows/deploy.yml`. После добавления проекта в GitHub:

1. В настройках репозитория открой **Settings → Pages**.
2. Выбери **Build and deployment → Source: GitHub Actions**.
3. Отправь ветку `main` или `master` в GitHub либо запусти workflow вручную во вкладке **Actions**.

Сборка автоматически использует имя репозитория как базовый путь, поэтому подходит и для адреса вида `username.github.io/repository/`.
