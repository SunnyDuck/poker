# Подключение Google Таблицы

Интеграция использует привязанный к таблице Google Apps Script как небольшой API. Публичное табло читает состояние из таблицы, а запись из админки требует отдельный ключ. Ключ хранится в свойствах Apps Script и в `sessionStorage` текущей вкладки; его нельзя добавлять в Git или переменные сборки.

## Настройка таблицы и Apps Script

Новая таблица уже создана: [Friendly Poker — хранилище сезона 1](https://docs.google.com/spreadsheets/d/1dFlXbRu1G1Fk9xl_Y4zzidWucesVoAbcJxMNBU_z-dk/edit). Откройте её в аккаунте Google, который будет владельцем турниров, затем:

1. Выберите **Расширения → Apps Script**.
2. Замените содержимое `Code.gs` кодом из этого каталога и сохраните проект.
3. Выберите функцию `setupPokerDatabase` и нажмите **Выполнить**. При первом запуске Google попросит разрешить скрипту доступ к таблице.
4. Откройте журнал выполнения и скопируйте строку `Friendly Poker admin key`. Сохраните ключ приватно; позже вставьте его в панель управления приложения. Повторный запуск `setupPokerDatabase` выпустит новый ключ.
5. Нажмите **Развернуть → Новое развертывание → Веб-приложение**. Установите **Выполнять от имени: я** и **У кого есть доступ: все**.
6. Подтвердите публикацию и скопируйте выданный URL, оканчивающийся на `/exec`.

Доступ **все** делает чтение турниров публичным: экрану не нужен вход в Google. Любой человек со ссылкой на скрипт сможет прочитать состояние турнира; поэтому не храните там закрытые или персональные данные. Изменение таблицы требует отдельный случайный ключ администратора, который не включается в публичный сайт.

Вкладка `_PokerData` хранит JSON-снимок состояния и номер версии. Меняйте данные через админ-панель приложения, а не вручную в этой вкладке. Публичный URL отдаёт данные для экрана, поэтому не добавляйте в турнирную модель закрытые или персональные данные.

## Локальный запуск

Создайте `.env.local` в корне проекта:

```dotenv
VITE_GOOGLE_APPS_SCRIPT_URL=https://script.google.com/macros/s/ВАШ_DEPLOYMENT_ID/exec
```

Затем перезапустите `npm run dev`, откройте `/admin`, вставьте admin key и нажмите **Включить запись**. Если таблица пустая, приложение запишет в неё текущее демо-состояние.

## GitHub Pages

В репозитории GitHub откройте **Settings → Secrets and variables → Actions → Variables** и добавьте переменную `VITE_GOOGLE_APPS_SCRIPT_URL` со значением URL `/exec`. URL не является секретом. Workflow использует эту переменную при сборке страницы; admin key в GitHub добавлять не нужно.

Экран перечитывает таблицу каждые пять секунд. Таймер хранит время старта и считает секунды локально на каждом устройстве, поэтому таблица не записывается каждую секунду. Первая версия рассчитана на одного администратора; не редактируйте один турнир одновременно из нескольких админских вкладок.
